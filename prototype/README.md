# Codex-O 原型交付包 v1.0

Codex CLI 中文用户的 Skill 管理 + 会话/Token 统计桌面工具的可编辑页面原型。纯 HTML + CSS + vanilla JS，零外部依赖（无 CDN、无外部字体、无网络请求），离线双击即可查看。

- 窗口基准：1280×800（Tauri 桌面窗口形态）
- 页面数：9（P0 精做 4 页 · P1 完整 4 页 · P2 占位 1 页）
- 设计系统：方案 A · Linear 定制（浅色优先），详见 `DESIGN.md`
- 需求来源：`BRIEF.md`

---

## 1. 打开方式

**方式一（推荐）**：直接双击 `index.html`，用浏览器（Chrome / Edge / Safari）打开。这是评审入口页，含 9 个页面的实时缩略预览与链接。

**方式二**：本地静态服务（避免极少数浏览器对 `file://` 下 iframe 的限制）：

```bash
cd prototype
python3 -m http.server 8080
# 打开 http://localhost:8080
```

无需安装任何依赖，无需构建。

## 4. 交互状态查看指引

每个产品页面顶部有一条灰色虚线 **PROTO 工具条**（由 `assets/app.js` 根据页面内 `window.PROTO` 配置自动注入，**不是产品 UI**），分三组按钮：

- **视图**：`正常 / 骨架屏 / 空数据 / 错误` —— 切换页面主区的状态视图（各状态区块在 HTML 中以 `<!-- ========== 视图: XXX ========== -->` 注释分隔）。各页可用视图以工具条实际按钮为准：列表类页面（列表 / 市场 / 更新 / 会话 / 统计）含全部 4 态；详情页为正常 / 骨架屏 / 错误（无空数据）；安装、设置、MCP 页仅正常态。
- **AI**：`正常 / 降级 / 不可用` —— 全局模拟 AI 服务状态。降级 / 不可用时：顶部出现提示横幅（不可用为红色）、AI 解析内容回退英文原文并标注、状态指示灯变化；横幅上的「重试连接」可演示恢复流程。
- **演示**：页面专属的交互演示按钮（触发弹窗、失败流程等，见第 5 节）。

快捷键：`⌘K`（或 `Ctrl+K`）聚焦当前页搜索框；`Esc` 关闭弹窗。

页面间跳转均为真实相对链接：列表卡片 → 详情页；市场 ⇄ 安装页；Token 统计 Top N → `sessions.html#detail`（由 JS 读取 hash 自动打开会话详情视图）；每页工具条右侧「← 评审入口」返回 `index.html`。

## 6. 可编辑指引

| 要改什么 | 改哪里 |
|---------|--------|
| 颜色 / 字体 / 间距 / 圆角 / 阴影 / 动效 | `assets/tokens.css` 中的 CSS 变量（命名与取值说明见 `DESIGN.md`） |
| 组件样式（按钮、卡片、弹窗、Toast、骨架屏、工具条等） | `assets/app.css` |
| 图标 | `assets/icons.js` 中 `window.ICONS` 的 SVG path（24×24 viewBox、stroke 风格） |
| 页面共享行为（视图切换、AI 模拟、弹窗、Toast） | `assets/app.js` |
| 某页数据（卡片、表格行、列表项） | 各页 HTML 的「视图: 正常」区块内，数据条目有 `<!-- ===== 数据 N ===== -->` 或卡片级注释标注，直接增删改 HTML 节点即可；筛选 / 排序 / 搜索基于 `data-*` 属性（如 `data-source`、`data-status`、`data-name`），新增条目时补齐同名属性即自动接入 |
| 某页独立交互 | 各页底部内联 `<script>`（安装流程、会话详情、图表渲染等页面私有逻辑） |
| 页面工具条配置 | 各页头部 `window.PROTO = { name, states, aiStates, actions }` |

注意：`assets/` 被全部 10 个 HTML 共享，修改前请确认影响面；页面私有样式写在各页 `<style>` 块内，优先级高于 `app.css`。

## 7. 已知遗留（P2 待办，不阻塞交付）

质量审查结论为 PASS（24/25），以下 2 条为 minor 建议，留待后续版本处理：

1. **tertiary 文本对比度 token 治理** —— `--color-text-tertiary` 在个别浅色底（如骨架屏占位块、禁用态卡片）上对比度接近 WCAG AA 下限，建议下一版统一梳理 tertiary 使用场景并拆分 token。
2. **collapse-head 键盘可访问性** —— 折叠组头部（`.collapse-head`）目前仅支持鼠标点击展开 / 收起，未绑定键盘焦点与 Enter / Space 触发，建议下一版改为 `<button>` 语义或补 `tabindex` + 键盘事件。
