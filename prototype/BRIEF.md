# Codex-O 原型需求摘要（Phase 1 产出 · 许明需）

## 一、设计需求五要素

| 维度 | 结论 |
|------|------|
| 场景 | 桌面管理工具（Tauri 2）的多页面可编辑 HTML 原型；按桌面应用窗口形态设计（1280×800，非浏览器全宽营销页） |
| 受众 | 主要：Codex CLI 中文深度用户（中高级开发者，已装 20+ skill）；次要：Codex 新手。技术素养高、重效率与信息密度 |
| 调性 | 中文优先、高效扫读（三秒法则）、先理解再操作、安全克制、降级可见 |
| 品牌 | 无既有品牌；借鉴 npm/brew 列表、VS Code 插件市场详情页、Cursor 统一管理面板 |
| 规模 | 9 个页面 + 统一应用外壳（侧边栏导航）+ 全局弹窗/状态层 |

## 二、页面清单（严格对应 PRD 9.1，共 9 页）

### ① Skill 列表页（首页）★ 全原型最重要页面
- **区块**：顶部搜索栏 → 筛选/排序栏（来源/状态/名称/安装时间）→ 用户 Skill 分区卡片列表 → 系统 Skill 分区（可折叠，标注不可卸载）
- **卡片字段**：图标、名称、中文一句话作用（AI 解析；降级时显示原始英文 description + "AI解析暂不可用"标注）、来源标签（本地/GitHub/市场/未知）、版本号（仅约 5% 有，多为"—"）、状态（正常 / 已禁用灰显 / 可更新角标）
- **操作**：搜索（实时过滤名称+中文解析内容）、4 维排序切换、点击卡片→详情、重新扫描

### ② Skill 详情页
- **区块**：头部（名称+来源+版本+目录路径）→ AI 中文解析区（🎯 作用 30-60字 / 📌 使用场景 3-5条"当用户…时" / 🔧 使用方式 50-100字含触发+示例）→ 相似 Skill 推荐（P1，"你可能也想看"，支持并排对比三要素）→ 元数据区（安装时间/来源/版本/文件大小/附属文件列表 references/scripts/agents）→ 原始英文 Description（折叠）→ SKILL.md 原文预览（折叠）
- **操作**：卸载（弹二次确认）、禁用/启用、重新解析（loading 态）、相似 skill 跳转/对比、返回列表

### ③ Skill 市场页（P1）
- **区块**：搜索栏 → 分类筛选 → 市场卡片网格（39 个 curated skill）
- **卡片字段**：图标、名称、shortDescription/description、安装状态（已安装置灰标"已安装" / 未安装显示"安装"）
- **操作**：搜索、分类筛选、点击未安装卡 → 安装前 AI 预览（轻量版：作用+场景）→ 安装按钮

### ④ 安装页（3 Tab）
- **Tab 1 本地导入**：选择 SKILL.md 文件 / 选择 skill 目录；格式校验反馈（frontmatter 须含 name+description）；同名冲突提示（覆盖/取消）
- **Tab 2 GitHub 拉取**：仓库 URL 输入（支持 user/repo、user/repo/subdir）→ 拉取中状态 → description 预览 + AI 中文预览 → 确认安装；失败显示错误原因
- **Tab 3 市场安装**：说明文案 + 跳转市场页按钮

### ⑤ 更新中心（P1）
- **区块**：顶部"一键检查更新"按钮 + 上次检查时间 → 可更新列表（名称/当前版本/最新版本/更新按钮）→ 已最新分组（折叠）
- **操作**：检查更新（5 秒内返回，loading 态）、单个更新、批量更新；更新完成 Toast"已自动重新解析"

### ⑥ 会话管理页（M3）
- **区块**：全文搜索栏（搜标题/首条消息/预览，结果高亮关键词）→ 按项目(cwd)分组的会话列表（组头：项目名+会话数+总Token+总大小，可折叠）→ 会话卡片 → 会话详情视图
- **会话卡片字段**：标题、模型、来源（vscode/cli/exec）、创建时间、Token 用量、文件大小、preview 摘要（前100字）
- **会话详情字段**：id / cwd / model / source / created_at / updated_at / tokens_used + git 信息（git_branch / git_sha / git_origin_url）+ 完整对话
- **完整对话**：按 rollout JSONL 顺序展示用户和助手的每一条可见消息；助手过程更新与最终回答分别标注；默认隐藏 developer、reasoning 和工具事件
- **操作**：排序筛选（时间/token/项目）、点击→详情、当前对话搜索、下载原始 rollout jsonl、删除（确认）、最近删除恢复、导出 CSV/JSON

### ⑦ Token 统计页（P1）
- **区块**：总览仪表盘 5 张统计卡（累计Token / 会话数 / 平均值 / 最大会话 / 本月用量）→ 维度切换 Tab（按项目/按模型/按来源/按时间）分布图 → 时间趋势图（日/周/月切换）→ 高消耗会话 Top N 排行 → 费用估算卡（显著标注"仅供参考"）→ 数据导出入口
- **操作**：维度切换、趋势周期切换、点击 Top N 会话→跳会话详情、导出 CSV/JSON

### ⑧ 设置页
- **区块**：AI 服务配置（Provider 三选一：OpenAI 兼容 / Anthropic / Ollama 本地；API Key；Base URL；模型下拉；Ollama 仅填服务地址无需 Key）→ 测试连接按钮 + 结果反馈 → 解析语言偏好（默认中文）→ 关于（版本/开源信息）
- **操作**：保存配置、测试连接、切换 Provider（表单联动：选 Ollama 隐藏 Key 字段）

### ⑨ MCP 管理页（P2 · 低优先级）
- **区块**：MCP Server 列表（名称/命令/参数/环境变量/启用状态）+ 增删改停
- **原型要求**：简化占位即可（列表 + 基础表单），页面标注"P2 · v1.x 后续"，不投入精细设计

## 三、交互状态清单

### 全局状态（每页适用）
| 状态 | 说明 | 原型呈现方式 |
|------|------|------------|
| 加载 | 列表/详情/统计页骨架屏；首次批量 AI 解析进度条 | 页面内状态切换器 + 注释 |
| 错误 | 目录扫描失败、state_5.sqlite 读取失败、AI 调用失败 | 关键页面出错误态画板/注释 |
| 空数据 | ① 无 skill → 引导导入/去市场；② 无会话；③ 搜索无结果 | 列表页+会话页各出 1 个空态 |
| AI 降级 | 顶部全局横幅："AI 解析暂不可用，已展示原始英文 description" + 「去设置」链接 | 全局组件，列表/详情页可见 |

### 全局弹窗/反馈（原型逐一呈现）
1. **卸载二次确认**：显示将删除的目录绝对路径 + 附属文件清单 + 危险警示；系统 skill 卸载按钮禁用态
2. **同名冲突提示**：覆盖 / 取消二选一
3. **测试连接结果**：成功（✓ 模型可用）/ 失败（错误原因）
4. **删除会话确认**：提示 rollout 大小、关联索引/Subagent 数量和回收站保留期
5. **最近删除**：展示可恢复会话与剩余保留时间
6. **更新完成 Toast**："已更新并自动重新解析"
7. **安装完成 Toast**："已安装，AI 解析完成"

> 实现建议：弹窗做成可切换显示的组件层；多状态用页面内注释 + 切换按钮/多画板呈现，保证单页可预览全部状态。

## 四、导航逻辑

**外壳**：左侧固定侧边栏 = Skill 列表（首页）/ Skill 市场 / 安装 / 更新中心 / 会话管理 / Token 统计 / 设置 / MCP 管理（标 P2）；顶部挂全局 AI 状态指示 + 降级横幅。

**页面间跳转**：
- 列表页 →点卡片→ 详情页 →返回→ 列表页
- 详情页 →相似推荐→ 另一 skill 详情 / 并排对比视图
- 市场页 →点未安装卡→ 安装预览（抽屉/弹窗）→安装→ Toast，卡片变"已安装"
- 安装页 Tab3 →跳→ 市场页
- 会话管理 →点会话卡→ 会话详情（页内视图）→返回
- Token 统计 →点 Top N 会话→ 会话详情
- 首次打开 / AI 未配置 →引导→ 设置页

**原型实现**：单 HTML 外壳 + hash 路由/锚点切换页面视图，9 页共享同一外壳。

## 五、真实示例数据（禁用 lorem ipsum）

### Skill 列表（21 用户 + 6 系统）
- skill 名：`frontend-design`、`ui-ux-pro-max`、`web-animation-design`、`impeccable`、`huashu-design`（5 个前端设计类，体现"功能重叠分不清"痛点）、`codex-token-usage`、`pdfkit-py`、`xlsx`、`agent-reach`、`tencentmap-map-assistant` 等凑满 21；系统区 6 个标 `.system/`
- 语言分布：13 英文（显示 AI 中文解析）/ 6 中文（直接提取）/ 2 混合
- 版本：仅 1-2 个有版本号，其余"—"；文件大小 2.6KB ~ 85.2KB 悬殊分布；67% 含附属文件
- 状态样例：1 个"已禁用"灰显、2 个"可更新"角标

### AI 三要素示例
- 作用："让 AI 生成高质量前端界面代码，注重设计审美与工程质量的平衡"
- 场景："当用户要求创建网页组件时" / "当用户需要提升界面设计质量时"
- 使用方式："自然语言触发，无需特殊命令。直接描述需求如'帮我设计一个登录页面'即可。需已安装 Tailwind CSS。"

### 市场（39 个）
字段按索引文件：id / name / description / shortDescription / icon / repoPath；description 英文为主、平均 301 字符

### 会话与 Token
- 54 会话、总 20.27 亿 token、均值 3,754 万/会话、sessions 566MB + archived 21MB
- 项目分组 Top3：**XOAssets 15.3 亿 / YT 2.3 亿 / ZreoPassword 1.3 亿**（再补 2-3 个小项目凑满 54 会话）
- 模型分布：**gpt-5.5 16.2 亿、gpt-5.6-terra 0.7 亿**；来源：vscode / cli / exec
- 会话标题用真实感中文开发任务名（如"修复登录页样式错乱"）
- 费用估算卡：按 gpt-5.5 定价粗估，显著标注"仅供参考"

### 设置页示例
Provider=OpenAI 兼容，模型 gpt-4o-mini；Ollama=http://localhost:11434；成本提示"全量解析约 ¥0.2"

## 六、特别注意事项
1. **精力分配**：列表页 > 详情页 > 设置页 > 会话管理页 > Token 统计页 > 市场/安装/更新中心 > MCP（占位级）
2. 危险操作（卸载/删除/覆盖）必须二次确认 + 路径展示
3. 所有界面文案中文；技术术语保留英文
4. 降级态与空态是一等公民，需同页可切换预览
5. P0 页面精做、P1 正常做、P2 占位；各页面标注优先级标签（P0/P1/P2）方便评审
