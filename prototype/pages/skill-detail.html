# Frontend Design

## Principles
- Semantic HTML first; ARIA only when semantics fall short
- One primary action per view; hierarchy via grayscale and weight
- Spacing on an 4px grid; measure twice, pad once

## Workflow
1. Read the existing design tokens / CSS variables before writing
2. Produce the smallest complete component that satisfies the brief
3. Audit with references/design-principles.md before final answer
