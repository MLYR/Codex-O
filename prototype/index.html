设计令牌合规说明

  • assets/tokens.css 原样收录 DESIGN.md §1 全部 :root 变量（含 dark 块）；组件规范中具名色（骨架底 / Toast 深底 / shimmer 高光等）统一补登记为变量。
  • 全部样式只引用 var(--*)；页面内 <style> 仅含页面专属布局（如同理引用变量）。可用 grep -n "#[0-9a-fA-F]\{3,6\}" assets/app.css pages/*.html 验证无硬编码色值。
  • 路径 / 版本号 / Token 数字 / 代码均走 --font-mono + tabular-nums；图标为 1.5px 线性内联 SVG（assets/icons.js），无 emoji、无外部字体/CDN。
  • 动效 ≤300ms、ease-out 为主、弹窗 fade+scale，含 prefers-reduced-motion 降级媒体查询。
